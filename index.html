About Rob-Links

Rob-Links is an independent gaming discovery directory that helps players explore browser games, classic WebAssembly ports, and external game projects.

1. Curated Directory

We catalog and test external browser games, WebAssembly ports, and open source gaming initiatives.

2. Direct Navigation

Every game launches directly to its verified external destination in a safe new browser tab.

3. Transparent Status

Games are labeled clearly as Browser Game, Project Page, or Files Required so you always know what to expect.
